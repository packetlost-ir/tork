# Tork

Secure, peer-to-peer terminal chat over Tor v3 onion services with End-to-End Encryption (E2EE).

## Prerequisites

- Python >= 3.10
- Tor daemon running locally with SOCKS5 proxy enabled (default `127.0.0.1:9050`) and ControlPort enabled (default `127.0.0.1:9051`).

## Quick Start

```bash
pip install .
tork
```
